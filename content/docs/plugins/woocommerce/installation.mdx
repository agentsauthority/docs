import { Callout } from 'fumadocs-ui/components/callout';
import { Steps, Step } from 'fumadocs-ui/components/steps';

## Install from WordPress admin

<Steps>
  <Step>
    ### Find the plugin
    In WordPress admin, go to **Plugins → Add New Plugin** and search for "Agents Authority".
  </Step>
  <Step>
    ### Install and activate
    Click **Install Now**, then click **Activate Plugin**.
  </Step>
</Steps>

## Install by uploading a ZIP

<Steps>
  <Step>
    ### Download the plugin
    Download `agentsauthority-woocommerce.zip` from your AgentsAuthority dashboard.
  </Step>
  <Step>
    ### Upload the plugin
    In WordPress admin, go to **Plugins → Add New Plugin → Upload Plugin**. Select the ZIP file and click **Install Now**.
  </Step>
  <Step>
    ### Activate
    Click **Activate Plugin**.
  </Step>
</Steps>

You'll see **Agents Authority** in your WordPress sidebar menu. Next: [connect your store](/docs/plugins/woocommerce/connect).

<Callout type="warn">
Before deactivating the plugin, disconnect your store first from **Agents Authority → Settings**. Deactivating without disconnecting leaves your store registered on the platform.
</Callout>
