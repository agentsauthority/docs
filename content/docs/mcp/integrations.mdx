Add your Agents Authority API key to any MCP-compatible client and your agent is ready to shop, manage wallets, and complete purchases.

Get your API key at [app.agentsauthority.com](https://app.agentsauthority.com) → Settings → API Keys.

---

## Claude Desktop

<Steps>
  <Step>
    ### Open config
    Mac: `~/Library/Application Support/Claude/claude_desktop_config.json`

    Windows: `%APPDATA%\Claude\claude_desktop_config.json`
  </Step>
  <Step>
    ### Add the server
    ```json claude_desktop_config.json
    {
      "mcpServers": {
        "agents-authority": {
          "url": "https://mcp.agentsauthority.com/mcp",
          "headers": {
            "Authorization": "Bearer YOUR_API_KEY"
          }
        }
      }
    }
    ```
  </Step>
  <Step>
    ### Restart Claude Desktop
    Quit and reopen Claude Desktop. You'll see a hammer icon in the input bar when tools are available.
  </Step>
</Steps>

<Callout>
  Try asking: "Find me a standing desk under $400" to verify the connection.
</Callout>

## Claude Code

Add to your project's `.claude/settings.json` or run the command:

```bash
claude mcp add agents-authority \
  --transport http \
  --url https://mcp.agentsauthority.com/mcp \
  --header "Authorization: Bearer YOUR_API_KEY"
```

Or manually in `.claude/settings.json`:

```json .claude/settings.json
{
  "mcpServers": {
    "agents-authority": {
      "type": "http",
      "url": "https://mcp.agentsauthority.com/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

## Custom agent (any MCP client)

If you're building your own agent, use the standard MCP HTTP transport:

```
Endpoint:  https://mcp.agentsauthority.com/mcp
Transport: Streamable HTTP
Auth:      Authorization: Bearer YOUR_API_KEY
```

<Tabs items={['Python (mcp SDK)', 'TypeScript (mcp SDK)']}>
<Tab value="Python (mcp SDK)">
```python
import mcp

client = mcp.Client(
    url="https://mcp.agentsauthority.com/mcp",
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)

result = await client.call_tool("aa_discover_products", {
    "query": "standing desk",
    "maxPrice": 400
})
```
</Tab>
<Tab value="TypeScript (mcp SDK)">
```typescript
import { Client } from "@modelcontextprotocol/sdk/client/index.js";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";

const client = new Client({ name: "my-agent", version: "1.0.0" });

await client.connect(new StreamableHTTPClientTransport(
  new URL("https://mcp.agentsauthority.com/mcp"),
  { headers: { Authorization: "Bearer YOUR_API_KEY" } }
));

const result = await client.callTool("aa_discover_products", {
  query: "standing desk",
  maxPrice: 400
});
```
</Tab>
</Tabs>
