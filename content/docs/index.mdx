## What is Agents Authority?

Agents Authority is the commerce infrastructure for AI agents. It lets AI agents — Claude, GPT, Gemini, or any MCP-compatible client — discover products, execute purchases, manage wallets, and interact with merchants, all through a single protocol layer.

## How it Works

```
AI Agent (Claude, GPT, etc.)
        ↓  MCP Protocol
Agents Authority MCP Server
        ↓  Commerce API
  ┌─────┴──────┐
  │   Platform  │  ← wallets, payments, mandates, policy
  └─────┬──────┘
        ↓  UCP Proxy
WooCommerce / Shopify Stores
```

AI agents connect to the MCP server, which exposes commerce capabilities as structured tools. When an agent wants to purchase a product, the platform handles authentication, payment authorization, policy enforcement, and merchant fulfillment — without the agent needing to understand any of it.
